# baselines/

Les **références simples** : des règles écrites à la main, sans IA (par exemple « montant nul ou négatif hors remboursement », « devise incohérente avec le pays »).

Elles servent d'étalon. Un mécanisme d'IA n'est jugé utile que s'il fait mieux que ces règles, seul ou combiné avec elles.
