# evaluation/

Les scripts qui **notent** chaque mécanisme en le comparant à la vérité terrain. C'est le **seul dossier** qui a le droit de lire les étiquettes.

Ils écrivent leurs résultats dans `results/metrics/` (un fichier par mécanisme, plus un tableau récapitulatif) et `results/figures/`. Le mémoire et les slides ne citent que ces fichiers.
