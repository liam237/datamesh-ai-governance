# mechanisms/

Les **dix mécanismes** de gouvernance, rangés selon le parcours d'une donnée :

| Dossier | Étape | Mécanismes |
|---|---|---|
| `arrival/` | 1. À l'arrivée | 1. Détection d'anomalies · 4. Données personnelles |
| `cleaning/` | 2. Au nettoyage | 3. Auto-correction · 9. Résolution d'entités |
| `publication/` | 3. À la publication | 7. Documentation générée · 8. Lignage |
| `consumption/` | 4. À la consommation | 5. Contrôle d'accès · 6. Analyse comportementale |
| `monitoring/` | 5. Dans la durée | 2. Dérives · 10. FinOps |

Règle stricte : **aucun mécanisme ne lit la vérité terrain.**
