# notebooks/

Les **notebooks Jupyter numérotés**, qui rendent la démarche d'analyse visible. Chaque analyse suit le même schéma : **on regarde** (un graphique ou un chiffre), **on conclut** (une phrase écrite), **on décide** (un traitement ou un réglage).

Prévu :
1. `01_exploration.ipynb` : distributions, saisonnalité, remboursements, valeurs manquantes ;
2. `02_traitement_et_variables.ipynb` : chaque transformation justifiée par un graphique ;
3. `03_resultats.ipynb` : matrices de confusion, courbes ROC et précision-rappel, comparaison règles / IA / combinaison.
